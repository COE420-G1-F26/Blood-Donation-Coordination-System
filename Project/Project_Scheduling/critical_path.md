## Explanation:

The critical path was found from the network calculations. A forward pass gives each task's earliest start (ES) and earliest finish (EF), and a backward pass gives its latest start (LS) and latest finish (LF). The slack of each task is then calculated as:

Slack = LS − ES = LF − EF

The tasks with a slack of 0 have no room for delay, so they form the critical path. Those are the tasks listed above. The path runs through both the Blood Bank branch (T10, T12, T16, T21) and the Hospital branch (T11, T13, T17, T22), which are identical in timing, so there are two critical paths. They meet at the merger point T19.

The final task T29 has EF = 88, so the project takes 88 days.

Every other task has slack above 0 (T9, T14, T15, T18, T23 and T27 have 35 days, and T20, T25 and T26 have 20 days), so they are not on the critical path.
