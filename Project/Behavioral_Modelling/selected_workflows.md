Following workflows were slected for activity Diagrams based on the use cases

- Send Blood (UC09): This usecase represents the process of a hospital making a request ot the blood bank for a certain quantity and type of blood.

- Store Default Options (UC05): This usecase represents the process of a hospital storing default blood requests in the system. If the hospital frequently requests certain types of blood in certain quantities, it can store default requests for this for convenience.

- Urgent Donation Diagram (UC07): This usecase represents the process of a donation drive organizer requesting urgent donations from donors to combat a shortage or surge in demand.
